# Results

One directory per measurement label, e.g. `m0-baseline/`, `m4-builders/`, `m4-tasks/`. Each holds the raw
per-run output (`<scenario>-<run>.txt`), the request-log aggregation (`models.md`) and a `NOTES.md` with
machine, commit hashes of both forks, distribution used, JDK, date. `REPORT.md` at this level is the
deliverable and is rewritten at M4 and M5.
